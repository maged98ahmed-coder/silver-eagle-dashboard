# Silver Eagle Dashboard 🦅

لوحة تحكم متكاملة لشركة Silver Eagle For Trade & Distribution of Cosmetics Product

## المميزات ✨

- 📊 **لوحة التحكم**: عرض إحصائيات المبيعات والأرباح والمصاريف
- 📈 **إدارة المبيعات**: تسجيل وتتبع المبيعات اليومية
- 💰 **إدارة المصاريف**: تسجيل ومراقبة جميع المصاريف
- 📦 **إدارة المنتجات**: إدارة المخزون والمنتجات
- ⚙️ **الإعدادات**: إدارة بيانات الشركة والحساب
- 🎯 **واجهة عربية**: دعم كامل للغة العربية (RTL)
- 📱 **تصميم متجاوب**: يعمل على جميع الأجهزة

## التثبيت 🚀

### المتطلبات
- Node.js (v16 أو أحدث)
- npm أو yarn

### خطوات التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/maged98ahmed-coder/silver-eagle-dashboard.git
cd silver-eagle-dashboard

# تثبيت المكتبات
npm install

# تشغيل الخادم الإنمائي
npm run dev

# بناء المشروع للإنتاج
npm run build
```

## الهيكل 📁

```
src/
├── App.jsx              # المكون الرئيسي
├── App.css              # نمط التطبيق الرئيسي
├── index.css            # الأنماط العامة
├── main.jsx             # نقطة الدخول
├── pages/
│   ├── Dashboard.jsx    # لوحة التحكم
│   ├── Sales.jsx        # صفحة المبيعات
│   ├── Expenses.jsx     # صفحة المصاريف
│   ├── Products.jsx     # صفحة المنتجات
│   └── Settings.jsx     # صفحة الإعدادات
└── styles/
    ├── Dashboard.css    # أنماط لوحة التحكم
    └── Pages.css        # أنماط الصفحات
```

## التقنيات المستخدمة 🛠️

- **React** - مكتبة واجهات المستخدم
- **React Router** - للتنقل بين الصفحات
- **Vite** - أداة البناء والتطوير
- **Lucide React** - أيقونات حديثة
